# NARUTO-KEYCHAINS
Some keychains that are made from eye designs from Naruto anime. they can be printed with or without an ams also they have hole to attach the keyring. they can be attached to bag packs, pouches etc. they are less filament using and only require one filament change.
<b>FEATURES:</b><br>
<ul>
  <li>fully 3d printed model</li>
  <li>3D design</li>
  <li>Can be printed without an ams</li>
  <li>multicolour design</li>
</ul>

<b>PRINT SETTINGS</b><br>
<ul>
<li>Filament: PLA<br></li>
<li>Infill density: 15-20%<br></li>
<li>Infill pattern: grid<br></li>
<li>Supports: disabled<br></li>
<li>Layer height: 0.2mm<br></li>
<li>Nozzle: 0.4mm<br></li>
<li>Speed: 150mm/s</li>
</ul>
